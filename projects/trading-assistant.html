AI trading assistant

An LLM trading agent built around discipline, not prediction. I write a strategy in plain English, it gets turned into code and backtested automatically, and only strategies that pass are allowed to trade, behind hard limits.

The problem

Before writing any code, I read through 200+ posts across 10 trading communities on Reddit to understand why retail traders lose money.

The pattern was consistent. The problem usually wasn't a bad strategy. It was breaking the rules of a decent one: overtrading, revenge trades, ignoring stop losses. So I decided to build a tool that enforces discipline rather than one that tries to predict the market.

How I approached it

Three ideas shaped the design. Strategies should be easy to state, so they're written in plain English. Nothing trades until it has been tested on real data. And the agent can never act outside limits I set in advance, no matter what it decides.

Build log

  1. Connect the agent to a broker

    I built the agent on Robinhood's Agentic API, connected through MCP. That gives the LLM a defined set of tools, like quotes, positions, and orders, instead of open-ended access.

  2. Turn plain-English rules into code

    Writing a backtest by hand for every idea took me about two hours. I built a backtester that takes a rule like "buy the 9:45 pullback if volume is above average" and turns it into testable code.

    Validation went from about 2 hours to about 5 minutes per strategy.

  3. Make every strategy earn its place

    Each strategy runs against six months of 5-minute price data. I set a bar: below a 70% win rate, it's cut.

    Of the first five strategies I tested, three failed and were rejected. That was the point. They would have felt convincing in the moment.

  4. Add guardrails

    The guardrails are the core of the project. Every order is reviewed before it's sent. The agent works in an isolated account. Daily trade limits cap how much it can do, so a bad decision stays small.

    I also added Pine Script v6 indicators so the same rules can be watched visually in TradingView.

  5. Put it in front of other traders

    I shared it in a Discord community. 15+ users have used it and reported that it helps them stick to their rules, which was the original goal.

What I learned

With LLM agents, the interesting engineering is in the constraints. Deciding what the agent is not allowed to do took more thought than anything it does.

Talking to users before building saved me from solving the wrong problem.
